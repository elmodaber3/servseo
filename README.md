## 📊 مميزات الأداة

### 1. 🔌 فحص المنافذ (Port Scanner)
- فحص شامل للمنافذ من 1 إلى 1000 (أو نطاق مخصص)
- كشف الخدمات العاملة على كل منفذ
- فحص متعدد المهام (Multi-threading) للسرعة

### 2. 🌐 جمع معلومات DNS
- كشف عنوان IP
- Reverse DNS Lookup
- معلومات DNS شاملة

### 3. 🖥️ معلومات السيرفر
- نوع السيرفر (Apache, Nginx, IIS, إلخ)
- التقنيات المستخدمة (PHP, ASP.NET, إلخ)
- رؤوس HTTP الكاملة

### 4. 🔐 فحص SSL/TLS
- إصدار SSL/TLS المستخدم
- نوع التشفير
- معلومات الشهادة
- تاريخ الانتهاء

### 5. 🛡️ فحص رؤوس الأمان
- Strict-Transport-Security (HSTS)
- Content-Security-Policy (CSP)
- X-Frame-Options
- X-Content-Type-Options
- X-XSS-Protection
- Referrer-Policy
- Permissions-Policy

### 6. 🐛 فحص الثغرات الشائعة
- المجلدات والملفات المكشوفة (/admin, /backup, /.env, إلخ)
- معلومات حساسة مكشوفة
- ملفات الإعدادات

### 7. 💉 اختبار SQL Injection
- اختبار المعاملات (Parameters)
- اكتشاف أخطاء SQL
- حمولات اختبار متعددة

### 8. ⚠️ اختبار XSS (Cross-Site Scripting)
- اختبار Reflected XSS
- حمولات XSS متنوعة
- اختبار المعاملات

### 9. 🎯 الفحص الشامل
- تشغيل جميع الاختبارات مرة واحدة
- تقرير شامل بجميع النتائج

### 10. 📄 إنشاء تقرير JSON
- حفظ النتائج في ملف JSON
- سهل الاستيراد والتحليل
- يحتوي على جميع التفاصيل
